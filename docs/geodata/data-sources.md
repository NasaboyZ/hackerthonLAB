# Verified geodata sources

## Basemap

- swisstopo vector style: https://vectortiles.geo.admin.ch/styles/ch.swisstopo.lightbasemap.vt/style.json
- Documentation: https://docs.geo.admin.ch/visualize-data/vector-tiles.html
- Attribution is rendered by MapLibre's attribution control.

The MVP uses the official light basemap directly. A dark transformation is intentionally deferred until the source layer structure is reviewed against the live style.

## Regulation sources

- Basel-Stadt: https://www.bs.ch/it/node/28962 — official guidance, verified 2024-06-21.
- Zürich: https://www.stadt-zuerich.ch/de/stadtleben/sicherheit/fragen-und-antworten.html — official guidance, including the Magnetfischer*innen section.
- Thurgau: https://archaeologie.tg.ch/public/upload/assets/154766/AA_Magnetfischen%20im%20Kanton%20Thurgau.pdf?fp=1 — official PDF, February 2024.

The first three records are published as verified non-spatial guidance. No legal polygon is shown until the official waterbody/protected-area geometry and its scope have been validated together.
